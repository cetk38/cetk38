# Samet Tok

Founder of **[AutoPriceData](https://www.autopricedata.com)** — a vehicle valuation API and brand-specific web and mobile solutions for dealerships, car dealers and vehicle-buying businesses.

AutoPriceData returns an **estimated market reference value** and the **offer price calculated with each business's own pricing rules** as separate fields, so a dealer can integrate valuation into its website, app or internal systems and set its own offers.
